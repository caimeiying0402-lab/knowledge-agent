# 职场新人如何应对信息不足与成长瓶颈

1. 职场新人面临两个核心问题：信息不足导致汇报被质疑，以及缺乏宏观视角只能当传话筒
1.1 问题1：内部汇报时自认信息足够，但仍被提出意料之外的问题
1.1.1 带教重复解释后对方理解，但新人认为获取信息相同，感到困惑
1.2 问题2：无法判断问题关联的人和事，只能被动领任务，担心成长缓慢
1.2.1 微观视角太久，未接触项目从0到1，无法判断状态、推动工作或移交任务
1.2.2 学习复盘速度跟不上问题产生速度，问题持续出现而学习滞后

2. 评论区建议：不同层级关注点不同，需结合组织架构和项目背景总结
2.1 执行层关注进度与完成时间，管理层关注风险与资源成本，战略层关注项目价值
2.2 解决信息不足：做好业务链条的干系人管理，超出范围的问题事后核查回复
2.3 解决宏观视角缺失：绘制业务流程图全览，拆分各阶段交付物和里程碑
