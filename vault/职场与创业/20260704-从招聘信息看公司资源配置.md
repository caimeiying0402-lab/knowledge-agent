# 从招聘信息看公司资源配置

1. 休三周年假后离职概率高，因时间足够完成求职流程
2. 招聘信息是公司公开写出的资源配置
2.1 岗位头衔可包装，但汇报关系难以伪装
2.2 职责动词“建立”“主导”暗示创造新能力，“维护”“执行”表示维持现状
2.3 任职要求中“降本”“合规”指向控制，“从0到1”“海外拓展”指向增长
2.4 新增岗位补能力，替代岗位暗示有人离开，长期挂岗可能预算未到位
3. 工资是滞后指标，反映过去；招聘是领先指标，反映未来
