# 简历写AI经历三要素

1. 简历写AI经历应聚焦方法、流程、结果，而非工具名
1.1 常见错误写法：只写“熟练使用Coze”“用AI辅助调研”，显得空洞
1.2 面试官无法判断候选人是会用AI还是只会复制粘贴
2. 写具体Skill或方法，而非仅写Prompt
2.1 示例：将“熟练使用AI辅助竞品分析”改为“搭建竞品拆解Skill，按用户场景、核心路径、转化入口、信息层级、可复用设计、产品启发六个维度输出”
2.2 这种写法表明候选人有自己的拆解框架，而非让AI随意生成
3. 写具体Workflow，而非“用AI提升效率”
3.1 示例：用户反馈分析写“用飞书多维表格+AI字段，将App Store评论、问卷反馈、访谈原文导入后，自动拆成原始反馈/问题分类/触发场景/情绪强度/建议动作，再用视图筛出高频问题”
3.2 关键：讲清数据来源、AI处理哪一步、最终进入哪个工作环节
4. 写可交付结果，而非仅“AI辅助”
4.1 示例：将“用AI辅助产品方案设计”改为“用Cursor/Codex将PRD草稿转成可预览页面Demo，先让AI生成基础页面，再手动调整信息层级、按钮状态和异常场景”
4.2 重点：AI参与后，最终形成能被检查、复用、交付的东西
