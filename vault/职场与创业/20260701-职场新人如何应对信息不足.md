# 职场新人如何应对信息不足

1. 职场新人面临两个核心问题：内部汇报信息被质疑，以及无法宏观理解项目全貌
1.1 问题1：内部汇报时，自认为信息足够，但仍被提出意料之外的问题
1.1.1 与外部沟通时对方答案足够，但内部汇报时被问及未想到的问题
1.1.2 基于现有信息回答，对方未感被解答或认为信息有误
1.1.3 带教重复解释后对方理解，但新人认为获取信息相同，感到困惑
1.2 问题2：不明白问题链接到哪些人和事，只能当传话筒，担心无成长
1.2.1 长期处于微观视角，未接触项目从0到1全过程
1.2.2 无法判断需求状态、推动工作、移交下一步
1.2.3 只能领一个任务干一个，学习速度跟不上问题产生速度

2. 不同层级关注点不同：执行层关注进度，管理层关注风险、资源和战略
2.1 新人层级关注项目进度和完成时间
2.2 +1层级关注风险点、所需资源和成本
2.3 +2层级关注项目的战略作用

3. 解决信息不足的方法：做好业务链条的干系人管理
3.1 超出自身范围的问题，事后核查回复，积累项目经验

4. 解决宏观理解不足的方法：回归业务流程，制作业务流程图全览
4.1 拆分每个阶段的交付物和标准
4.2 明确每个阶段的里程碑
