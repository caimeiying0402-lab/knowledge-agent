# 与身体谈恋爱走出病痛

1. 将身体视为恋爱对象，以积极心态走出病痛
1.1 身体细胞和器官无怨无悔地爱着我们，即使我们常伤害它
1.2 作者生病时自暴自弃，受帖子触动决定回应身体的爱意
2. 以恋爱方式爱身体：照顾情绪和取悦心情
2.1 照顾情绪：骑车时拉好拉链防着凉，不熬夜，受伤时忏悔道歉
2.2 取悦心情：学习养生知识，慢跑分泌内啡肽，保持乐观带动身体积极
3. 心理积极情绪带动身体积极，实现身心双倍开心
4. 实践后睡眠改善、病情好转、精神不再乏力
5. 被身体坚定不移地爱着，带来自信和面对困难的勇气
