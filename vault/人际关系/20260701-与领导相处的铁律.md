# 与领导相处的铁律

1. 与领导相处的铁律：他靠什么上来，就用什么方式相处
1.1 领导靠背景被提携 → 忠心不犯错，多讲情谊少谈业绩
1.2 领导靠实干干上来 → 只认结果，花言巧语是扣分项，踏实高效执行
1.3 领导靠经营关系、揣摩上意上来 → 会说话、适度捧场、懂人情往来，要的是会做人
