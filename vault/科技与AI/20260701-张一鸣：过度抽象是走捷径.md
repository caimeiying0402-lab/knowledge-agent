# 张一鸣：过度抽象是走捷径

1. 张一鸣在CEO面对面中强调：过度抽象是走捷径
1.1 过度抽象是对方法论的过度追求
1.2 方法论在大部分情况下可能没什么用
2. 对事物抽象相当于给思维加杠杆
2.1 杠杆加错会导致失之毫厘、谬以千里
3. 不要装逼，避免过度抽象
4. 聚焦于如何做出好产品
