# Claude Code AI编程助手

Claude Code 是 Anthropic 推出的 AI 编程助手，它可以直接在你的终端中运行。与传统的 IDE 插件不同，Claude Code 是一个命令行工具，它能够理解整个代码库的上下文，支持多文件编辑、Git 操作、运行测试和调试。安装方法：npm install -g @anthropic-ai/claude-code
