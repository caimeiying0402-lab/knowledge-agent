# Claude.md文件使用指南

1. CLAUDE.md是Claude Code启动时自动读取的持久化指令文件，拼接到system prompt中
2. 记忆管理分四层：全局层、项目层、本地覆盖层、子目录层
2.1 全局层(~/.claude/CLAUDE.md)：所有项目加载，适合个人编码偏好
2.2 项目层(项目根目录)：提交到git，团队共享，使用最多
2.3 本地覆盖层(CLAUDE.local.md)：加进.gitignore，仅本地生效
2.4 子目录层：按需加载，对monorepo友好
2.5 越靠近工作目录的配置，优先级越高
2.6 不同层级CLAUDE.md文件不能互相矛盾
3. 只写入AI无法推断的内容，如特定业务规则
3.1 例：视频生成平台用户群体面向金融行业，写入项目CLAUDE.md
4. 维护节奏：先干活积累成果，跑/init生成基础版
4.1 Claude自动往memory积累跨会话经验
4.2 定期review memory内容，提炼通用经验进CLAUDE.md，清理过时条目
