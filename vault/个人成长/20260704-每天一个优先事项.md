# 每天一个优先事项

1. 个人成长应避免平均主义，核心方法是每天只设定一个优先事项
1.1 优先事项数量为一个，不是三个或五个
1.2 当天无论如何必须完成该事项
1.3 完成优先事项即算成功，无论其他事是否发生
1.4 给优先事项留出固定时间，哪怕只有15分钟
2. 大多数人一整个星期完不成一件重要事，因所有事感觉同样紧急
2.1 时间精力有限，能做的事少之又少
2.2 必须划出优先级，先解决影响范围最大的事
3. 选择优先事项困难时，选一个做起来稍费力的
3.1 坚持做一个月，下个月会选得更准确
