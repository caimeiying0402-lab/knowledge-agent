# 职场技术vs管理路线选择

1. 职场路线选择由性格和做事风格决定，盲目跟风或死磕是误区
1.1 技术路线适合不爱社交、耐枯燥、专注深耕的人
1.2 管理路线适合情商高、懂人性、擅长沟通和统筹的人
1.3 管理核心是让团队能干、帮结果落地，而非自己技术顶尖
2. 选对赛道可少走10年弯路，避免两头落空
3. 建议先深耕技术，达到上限后转向管理或创业
