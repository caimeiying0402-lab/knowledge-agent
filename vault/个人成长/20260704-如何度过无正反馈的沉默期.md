# 如何度过无正反馈的沉默期

1. 真正向上的路前期昏暗且体感像后退，这是筛选和积累的关键阶段
1.1 拉开人与人差距的关键在于无反馈期
2. 度过无反馈期的三个方法
2.1 戒掉反馈依赖：一开始反馈多的事走不远，改变命运的事反馈通常少
2.2 最小化动力支点：靠向内看而非外界认可驱动，每天问自己是否有进展
2.3 不完美的出发：先完成再完善，连续性本身是最高战略
3. 评论区观点
3.1 高赞评论集中在“明道若昧，进道若退”“怕输焦虑，想赢兴奋”等总结
3.2 有观点认为做事有不同反馈形式，如健身的肌肉酸痛、充血
3.3 有评论认为足够坚定则不会把无反馈当黑暗，否则只是想要结果
3.4 作者回应：初级阶段靠强者思维扛过去，高阶状态视做事本身为答案
4. 无反馈期不是失败信号，而是区分真正想做与只想要结果的分水岭
