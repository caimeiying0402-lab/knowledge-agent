Key Capabilities

Multi-Source Ingestion

URL/Text/Image/WeChat → AI summarization with 19-category classification. Supports Xiaohongshu, WeChat MP, and JS-rendered pages via Playwright.

Dual-Mode Search

Hybrid search combining ChromaDB vector (semantic) + SQLite keyword (exact). ONNX local embedding, zero API cost.

AI-Powered Discovery

Automated web discovery based on knowledge base interest profiling. DeepSeek scoring + dedup + push notification.

7x24 Cloud Gateway

Cloudflare Worker edge computing. Messages never lost even when Mac is offline. D1 queue + R2 permanent image storage.
